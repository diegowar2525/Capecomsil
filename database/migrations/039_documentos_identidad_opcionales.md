# Documentos de identidad opcionales

Permite cédula de chofer y RUC de proveedor nulos. Conserva los índices únicos para documentos informados. API normaliza blancos a NULL y rechaza valores no textuales. No cambia gasolineras.

Ejecutar `039_documentos_identidad_opcionales.sql` en la base antes de registrar choferes sin cédula. No ejecutada durante la auditoría de enero. No requiere rellenar documentos ficticios.
